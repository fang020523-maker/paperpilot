## 现场答辩演示走位（8 分钟版）

1. **文献库**（1min）：拖入 1 篇新 PDF，走一遍导入管线七阶段（提前用 SKIP_EXTRACT 说明两种模式）
2. **问答主秀**（2min）：S2 问题 + S3 问题，指着时间线讲三论文机制
3. **引用溯源**（0.5min）：点开引用弹窗
4. **隐私模式**（1.5min）：切档 → WebGPU 徽标 → 提问（若证据不足即展示拒答——照样加分）
5. **图谱**（1min）：悬停高亮 + 点节点看一跳关系
6. **评估**（1min）：雷达图 + 一键对比实验按钮（讲清 6 题×双管线，进度条出现即可切走）
7. **MCP/收尾**（1min）：口播 MCP 标准端点（curl 示例在 README），谢幕

## 现场演示应急预案（务必预演一次）

### 限流 / 风控（错误码 1314 / 1302 / 429）
智谱免费/受限账号在**持续高频调用**下可能触发账号级风控（单次提问仍正常）。系统已内置多层自愈（多密钥轮换 → 模型级回退 → 熔断器），但现场仍需预案：

1. **话术**："该账号触发平台级速率限制，系统正在自动回退到备用模型——这正是我们降级链设计的场景。"（边说边等 5-15 秒，熔断器会自动切备模型）
2. **节奏控制**：演示问题之间留 10 秒以上间隔；不要连续快速点击"一键对比实验"（该功能 6 题×双管线约 10 分钟，演示时讲进度条即可切走，不现场等完）
3. **兜底切换**：若持续失败 → 切"基线"档演示单轮管线（链路最短、成功率最高），或展示已录制的 v2 视频
4. **预热**：演示开始前 5 分钟先完整问 1 个问题（激活熔断器状态与模型连接）

### 语音输入注意
- Web Speech API 依赖浏览器麦克风权限：**首次点击会弹权限框，演示前先在 Chrome 授权一次**
- 评委现场环境嘈杂时优先用键盘输入，语音作为"无障碍能力"展示 10 秒即可
- IAB/部分内嵌浏览器可能不支持该 API（按钮自动隐藏属正常）；正式演示用 Chrome/Edge

### 隐私模式注意
- 首次同步 1321 片段需数分钟（WASM 慢、WebGPU 快，视浏览器而定）；**演示前提前切一次隐私档完成同步**，现场切换即"WebGPU/WASM · N 片段"秒就绪
- 端侧段可主动展示一次"证据不足拒答"——这比成功回答更能体现 Sufficient Context 安全设计
