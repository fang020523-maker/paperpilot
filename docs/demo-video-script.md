# PaperPilot 演示视频脚本（5-8 分钟 · 1080p）

> 录制环境：Chrome（开启 WebGPU），智谱密钥已配置，知识库已导入 15 篇演示论文。
> 全程录屏 + 口播，节奏参考：痛点 45s → 导入 60s → 问答/时间线 90s → 图谱 60s → 隐私 50s → 评估 45s → MCP/安全 40s → 总结 30s。

---

## 0. 片头（0:00-0:15）

- 画面：首页空状态，品牌名「PaperPilot 文翰」渐显，技术标签逐个点亮
- 口播：*"科研人员每年读几百篇论文——找不全、关联难、AI 回答又不敢信。我们做了 PaperPilot，一个能看到 AI 思考过程的文献问答系统。"*

## 1. 痛点与导入流程（0:15-1:15）

- 画面：切到文献库页，拖入 3 篇论文 PDF（提前放桌面）
- 镜头重点：
  1. 任务卡片逐阶段跳动：`浏览器内解析 PDF → 抽取元数据 → 结构化分块 → 上下文增强分块 → 生成向量嵌入 → 抽取实体关系 → 重建主题社区`
  2. 一张卡片展开，指到「上下文增强」阶段说一句 Anthropic Contextual Retrieval
- 口播：*"PDF 在浏览器里解析，原文不出本地。导入管线做了七步：结构化分块、LLM 为每个分块生成上下文前缀、向量化、实体关系抽取、社区摘要——右边这些论文标题、年份，全是自动抽取的。"*

## 2. 智能问答 + AI 思考时间线（1:15-2:45）★核心镜头

- 问题 1（事实类）：**"Self-RAG 用什么机制控制检索时机？"**
  - 镜头：时间线展开——分类路由（标注「事实查询」）→ 混合检索（展开看：改写、多视角、HyDE 徽标、8 个候选带分数）→ 回答流式输出，[1][2] 引用徽标在下方
  - 口播：*"注意左侧时间线：系统先判断问题复杂度——这是 Adaptive-RAG；然后混合检索，BM25 加向量加 HyDE 假设文档，RRF 融合后重排序；回答里每个论断都有 [n] 引用，点开就是论文页码。"*
- 问题 2（多跳类）：**"哪些论文用了相同的数据集？各自报告了什么结果？"**
  - 镜头：时间线出现「图谱邻域检索」步骤，展开显示命中的实体与关系三元组；切到知识图谱页找到对应实体高亮（可提前演练找到位置）
  - 口播：*"多跳问题靠知识图谱：实体邻域把不同论文通过共享数据集连起来——这是纯向量检索做不到的。"*
- 问题 3（综述类）：**"知识库里的论文覆盖了哪些主要技术路线？"**
  - 镜头：时间线显示 `graph_search global`，展开显示社区摘要；回答呈现各主题社区概括
  - 口播：*"领域综述走 GraphRAG 全局模式，Louvain 社区摘要直接作为证据。"*

## 3. 知识图谱页（2:45-3:45）

- 镜头：滚轮缩放、拖动节点、悬停某实体高亮邻域、点击节点侧栏展示 1 跳关系与「×N 证据」
- 操作：关/开「社区聚类着色」开关展示 Louvain 效果；拖动最小提及滑杆观察图密度变化
- 口播：*"图谱是导入时自动构建的：方法、数据集、指标、模型八类实体，每条关系都带原文证据句。颜色是 Louvain 社区聚类，侧栏还能看到每个社区的主题摘要。"*

## 4. 端侧隐私模式（3:45-4:35）★差异化镜头

- 镜头：顶部切到「隐私」档 → 状态徽标显示 `端侧嵌入 xx%` → 完成后显示 `WebGPU · N 片段`
- 打开 DevTools Network 面板（提前开好，过滤器 `api`）：提问一个问题，指给观众看**没有任何 PDF 全文或全库导出请求**，只有一次小体积的片段生成请求
- 口播：*"隐私模式：向量嵌入和检索都在浏览器里跑——WebGPU 加速的 e5 模型，存在 IndexedDB。看网络面板：只有命中的五个片段参与了生成，论文全文不出浏览器。未发表的稿子也能放心问。"*

## 5. RAGAS 质量评估（4:35-5:20）

- 镜头：回答下方的 RAGAS 四指标条出现动画 → 切到「质量评估」页：均值卡片、雷达图（Agentic vs 基线）、趋势折线、历史明细
- 操作：同一问题在「基线」档再问一次，回到仪表盘看雷达图对比变化
- 口播：*"每次回答都被独立 LLM 评委按 RAGAS 四指标打分：忠实度、相关性、精确率、召回率。顶部可以切到朴素 RAG 基线做同题对比——这套 Agentic 管线带来的提升，是系统自己量化的，不是我们口头说的。"*

## 6. 多模态 + MCP + 安全（5:20-6:00）

- 多模态：点麦克风图标说一个问题（语音自动填入）；对一条回答点朗读按钮
- MCP：切终端，粘贴运行：
  ```bash
  curl -X POST localhost:3000/api/mcp -H "Content-Type: application/json" \
    -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"search_papers","arguments":{"query":"reflection tokens"}}}'
  ```
  展示 JSON 返回的检索结果
- 口播：*"检索器同时暴露为标准 MCP 服务——Claude 或任何 MCP 客户端都能直接把 PaperPilot 当工具用。安全侧：上下文注入过滤、库外拒答、AI 生成标识。"*

## 7. 收尾（6:00-6:30）

- 画面：回到问答页，镜头缓慢拉远展示四个页签
- 口播：*"Adaptive 路由、CRAG 纠错、Self-RAG 反思、GraphRAG、HyDE、RAGAS——12 篇论文的技术，一个看得见思考过程的文献助手。PaperPilot 文翰，谢谢观看。"*
- 片尾字幕：技术栈 + 团队名 + 仓库地址
